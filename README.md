# نظام إدخال بيانات المنتجات (Streamlit + SQLite)

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```
يفتح على http://localhost:8501

## الملفات
- `app.py` — الواجهة
- `core.py` — منطق السكيما + قاعدة البيانات + التصدير
- `Full_Printing_Packaging_Schema_REVISED.xlsx` — السكيما (يجب أن يبقى بجانب app.py)
- `catalog.db` — قاعدة البيانات (تُنشأ تلقائيًا عند أول تشغيل)

## كيف يعمل
1. تختار Product Type ثم Subtype، فتظهر الخصائص المطلوبة لهذا المنتج فقط (من شيتات PROPERTIES_BY_TYPE و SUBTYPE_PROPERTIES).
2. الخصائص ذات القيم المحددة = قائمة منسدلة، وبعضها متعدد الاختيار (مثل المناسبات، التشطيب، الألوان...).
3. اختيار custom/other يفتح خانة لكتابة التفاصيل.
4. التسعير: fixed_price / custom_formula / quote_price — وتظهر الحقول المناسبة فقط.
5. من صفحة التصدير: Excel / CSV / JSON / ملف قاعدة البيانات.

## إعدادات اختيارية (متغيرات بيئة)
- `APP_PASSWORD` — يفعّل شاشة كلمة مرور.
- `CATALOG_DB` — مسار ملف قاعدة البيانات (مفيد عند الاستضافة مع تخزين دائم).
- `SCHEMA_FILE` — مسار ملف السكيما.

## تنبيه الاستضافة
على Streamlit Community Cloud ملفات الـ SQLite تُمسح عند إعادة التشغيل. استخدم سيرفر/Render/Railway مع Volume دائم،
أو شغّله محليًا عند العميل، أو اطلب منه تحميل نسخة .db بشكل دوري من صفحة التصدير.

## تعديل السكيما
- عدّل ملف Excel وأعد تشغيل التطبيق: الأنواع والخصائص والخيارات تتغير تلقائيًا.
- الخصائص متعددة الاختيار معرّفة في `MULTI_PROPS` أعلى `core.py`.
- القوائم المقترحة (الاستخدامات، القطاعات، العملات) أعلى `core.py` أيضًا.
